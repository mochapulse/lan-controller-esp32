Detailed Description

Unit tests for the Wake-on-LAN module.

Tests MAC format validation, hex character validation, wol_init() parameter validation, and wol_send() state guard. Each test resets the WoL module state to ensure isolation.

Test:

Valid and invalid hex characters.

MAC string format validation edges.

NULL and invalid parameter rejection.

Valid parameter acceptance.

State guard before init.
