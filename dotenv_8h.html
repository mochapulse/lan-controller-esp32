Detailed Description

Embedded .env parser — stores up to 16 key/value pairs in static arrays parsed from a binary blob linked via objcopy.

The .env file is embedded at build time by CMakeLists.txt using objcopy. Symbols: _binary__env_start / _binary__env_end.

Note
Call dotenv_init() once before any dotenv_get() / dotenv_get_int(). All returned pointers are valid for the program lifetime.
