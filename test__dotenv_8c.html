Detailed Description

Unit tests for the dotenv embedded .env parser.

Tests the line-parsing logic (dotenv_parse_line) and the lookup functions (dotenv_get / dotenv_get_int) independently of the flash-embedded .env blob. Each test resets the internal entry table to ensure isolation.

Test:

Basic KEY=VALUE parsing.

Quoted value handling.

Leading/trailing whitespace stripping.

Comment-line skipping.

CRLF trailing character stripping (\r).

Missing-key returns NULL.

Default falue fallback.
