Detailed Description

Embedded .env parser implementation.

Parses KEY=VALUE lines from an objcopy-embedded binary blob. The blob is stored in read-only flash (rodata section); parsing happens once at startup into a fixed-size static table.

objcopy names are derived from the file path by replacing non-alphanumeric characters with underscores: 

".env"  ->  \c _binary__env_start  /  \c _binary__env_end
